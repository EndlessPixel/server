# 📦 Launcher & Mod-Pack Downloads

Provides high-speed downloads for 80+ mainstream Minecraft launchers and mod-packs, with custom mirror sources for different network conditions.

## Features

- Clear categories: official launchers, third-party launchers, and mod-packs in separate sections.
- Fast download: built-in mirror acceleration; switch to a custom mirror on slow networks.
- Responsive: looks great on both phone and desktop, with one-click copy of direct links.

## Edition Policy

- The server supports **Java Edition only** (including mobile Java launchers such as POjavLauncher).
- **Not supported**: Bedrock Edition and web/browser clients.
