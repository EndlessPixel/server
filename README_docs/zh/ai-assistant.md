# 🤖 AI 助手（epbot）

站内智能问答助手，基于流式聊天，针对服务器常见问题（接入方式、版本、活动、封禁申诉等）做了知识库与提示词优化。

## 核心能力

- **流式回复**：逐字输出，体验顺滑；复杂问题会引导 AI 使用 `<thinking>` 多步推理。
- **服务器上下文注入**：将服务器状态、版本、知识库（含"仅支持 Java 版、不支持基岩/网页版"等口径）注入系统提示，让回答更贴合本服。
- **交互卡片（Widget）**：AI 可在回复中插入结构化卡片，例如 QQ 群卡片、服务器信息卡，用户可直接查看/复制。

## 卡片渲染机制

为避免 Markdown 解析破坏卡片标签，采用**分段渲染**：

1. 渲染前按自闭合 `<widget .../>` 把文本切分为「Markdown 文本段 / 卡片段」。
2. 文本段交给 ReactMarkdown 渲染；卡片段直接渲染真实组件（`<WidgetTag/>`），**永不进入 Markdown 解析**，因此不会被吞掉、也不会漏出占位符。
3. 卡片组件使用 `React.memo`，复制/重渲染不会触发刷新或重复请求。
4. 流式输出时，**完整**的 `<widget/>` 立即渲染；**未完成**（未收到 `/>`）的标签临时隐藏，完成后自动还原，避免无限 loading。

## 链接安全

AI 输出的外链统一改写为站内中转页（`/ai_link?url=...`），在打开前可做提示，防止直接跳转风险链接。
